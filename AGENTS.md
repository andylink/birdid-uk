# AGENTS.md

## Project

Real-time garden bird classifier: Python daemon (`detect.py` / `main.py`) → BirdNET or Perch inference → SQLite → FastAPI dashboard + SvelteKit frontend. UK-focused with BOU/BTO species allowlist, GBIF-derived seasonal filter, and time-of-day nocturnal filter.

## Developer commands

**Python detector**
```sh
# use the repo venv (Python 3.11)
source venv/bin/activate

pip install -r requirements.txt   # all deps (detector + dashboard) in one file

python detect.py                  # run detector daemon only
python main.py                    # run detector + dashboard in one process (dev/SBC)
python main.py --host 127.0.0.1 --port 9000   # custom bind address

# find the correct audio device index for config.toml [audio] device
python -m sounddevice

# regenerate uk_seasonal_filter.json from GBIF data
python build_uk_seasonal_filter.py
```

**Dashboard backend (standalone)**
```sh
uvicorn dashboard.app:app --host 0.0.0.0 --port 8080 --reload
```

**Frontend** (run from `dashboard/frontend/`)
```sh
npm install
npm run dev          # Vite dev server; proxies API calls to localhost:8080
npm run check        # svelte-kit sync + svelte-check (type-check)
npm run build        # production build → dist/ (required for FastAPI to serve UI)
```

Override the proxy target: `API_BASE=http://other-host:8080 npm run dev`

**Systemd (production)**
```sh
sudo cp systemd/birddetector-*.service systemd/birddetector.target /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now birddetector.target
```

## Key architecture notes

- **Single config file**: everything lives in `config.toml`. Do not add `.env` files or hardcode values; read `config.toml` through `config.py`.
- **`dashboard/config.py`**: reads all values from `cfg` (the detector's config singleton). `lat`/`lon` and `timezone` are now correctly read from `config.toml` via `cfg.location` and `cfg.general`. There is no longer a hardcoded-values bug here.
- **Unified entrypoint**: `main.py` runs the detector (daemon thread) and the FastAPI dashboard (uvicorn on main thread) in a single process. Use `detect.py` alone when running detector and dashboard separately. For production use the systemd services in `systemd/`.
- **Dual-buffer design**: the recording thread feeds two consumers: `audio_queue` (sliding analysis window for inference) and `_capture_buffer` (a ring buffer, default 30 s). On detection, a deferred-save task reads the full clip from the ring buffer after a post-capture sleep, mirroring BirdNET-Go's CaptureBuffer design.
- **Clip modes**: `[audio] clip_mode = "window"` saves the model analysis window + `window_pad_seconds` of leading audio (compact, ideal for fine-tuning). `clip_mode = "full"` uses the legacy `clip_seconds` / `pre_capture_seconds` / post-capture geometry. Clips are saved as **FLAC** (not WAV).
- **Inference model abstraction**: `inference.py` is a dispatcher. Each backend (`inference_birdnet.py`, `inference_perch.py`) exposes `window_seconds`, `run_inference()`, and `load_label_map()`. `detector.py` uses `model.window_seconds` to size its rolling audio buffer, so the buffer resizes automatically when the model changes (BirdNET: 3 s, Perch: 5 s).
- **BirdNET labels**: uses standard IOC English labels bundled with `birdnet-analyzer` (no `label_locale` config). BTO British name translation (e.g. "European Robin" → "Robin") is done downstream by `bou_filter.build_birdnet_to_bto_map()` via `species_bto_FINAL_filtered.json`.
- **Confirmation filter**: each species must exceed `min_confidence` at least `min_detections` times within `confirmation_window_seconds` before a clip is saved. This suppresses transient false positives. Set `min_detections = 1` (per-species override) to save on the first hit.
- **Cross-validation** (`cross_validate.py`): when `[cross_validation] enabled = true`, every confirmed detection is re-run through the secondary model (whichever of BirdNET / Perch is not primary). Agreement is checked at the BTO-name level to bridge IOC/eBird label namespaces. On disagreement, the detection is either dropped (`on_disagree = "drop"`) or saved with `flagged = true` (`on_disagree = "flag"`). High-confidence primary detections skip CV via `skip_threshold`.
- **Filters pipeline** (applied in order in `_classify_loop`): exclude list → per-species `min_confidence` → BOU allowlist → seasonal filter → nocturnal filter → confirmation filter → cooldown.
- **Nocturnal filter** (`nocturnal_filter.py`): loaded from `uk_nocturnal_filter.json`. Supports `sunset_sunrise` windows (computed from `[location]` lat/lon via `astral`) and `fixed` clock-time windows. Per-species overrides via `active_hours` in `[species."Name"]` blocks in `config.toml`.
- **BOU filter**: `[bou_filter] exclude_status` token list (e.g. `["Accidental"]`) suppresses vagrant species. Per-species `bou_status_override = true` admits a species regardless of its status.
- **Database schema**: created automatically via SQLAlchemy `create_all` on first run. Cross-validation columns are added to existing databases via `_migrate_detections_table()` (ALTER TABLE). No migrations framework. The dashboard uses `aiosqlite` directly; the detector uses SQLAlchemy. SQLite runs in WAL mode.
- **`species_bto_FINAL_filtered.json`** is a checked-in data file (BTO species list). `uk_seasonal_filter.json` is generated by `build_uk_seasonal_filter.py` — edit the script, not the JSON directly.
- **Retention** (`retention.py`): background thread deletes old FLAC clips by age (`max_age_days`) and/or disk usage (`max_usage_percent`), always keeping `min_clips_per_species` newest clips per species.
- **Production serving**: FastAPI mounts `dashboard/frontend/dist/` at `/`. Run `npm run build` before running the server in production; the `dist/` directory is gitignored.
- **Vite dev proxy**: `/api/v1`, `/stream`, `/audio`, `/spectrogram`, `/healthz` are proxied to the FastAPI backend. `/api/v2/*` requests are absorbed silently (intentional workaround for OpenCode health-checks).
- **Svelte 5 runes mode** is enabled project-wide (`svelte.config.js`). Use `$state`, `$derived`, `$effect` — not legacy `export let` / reactive statements.
- **Frontend can import project-root JSON** (e.g. `species_bto_FINAL_filtered.json`) because `vite.config.ts` sets `server.fs.allow` to the repo root.
- **Wikimedia image cache**: `dashboard/routes/species.py` fetches species photos from Wikipedia on demand and caches them under `data/species_images/`. A `.jpg` file is a positive cache hit; a `.none` file is a negative sentinel (retried after 1 day). Images expire after 30 days.
- **`constants.py`**: `NOISE_LABELS` frozenset filters non-bird sounds (BirdNET catch-alls + 198 Perch FSD50K classes) inside `run_inference()` before results reach the detect loop.

## API routes (FastAPI)

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/v1/detections` | List detections; filters: `species`, `date` (YYYY-MM-DD local), `flagged`, `limit`, `offset` |
| GET | `/api/v1/species` | Species list with stats; filters: `period`, `sort`, `bocc`, `status`, `group`, pagination |
| GET | `/api/v1/species/{name}` | Aggregate stats + `species_info` metadata for one species |
| GET | `/api/v1/species/{name}/detections` | Paginated detection recordings for one species |
| GET | `/api/v1/species/image` | Serve cached Wikimedia species photo (`?name=...`) |
| GET | `/api/v1/analytics/species/daily` | Per-species daily summary + 24-element hourly_counts array |
| GET | `/api/v1/analytics/by-hour` | Total detections grouped by local hour |
| GET | `/api/v1/analytics/summary` | Headline stats (totals, conservation counts, conservation_score) |
| GET | `/api/v1/analytics/top-species` | Top-N species by detection count |
| GET | `/api/v1/analytics/new-species` | New-species-per-day timeline |
| GET | `/api/v1/analytics/bocc-breakdown` | Unique species + detection count by BoCC status |
| GET | `/api/v1/analytics/bocc-trend` | Daily detection counts by BoCC status (stacked bar data) |
| GET | `/api/v1/analytics/group-breakdown` | Detections + species count per taxonomic group |
| GET | `/api/v1/sun` | Sunrise/sunset times (`?date=YYYY-MM-DD`) in configured local timezone |
| GET | `/api/v1/config` | Public runtime config: `timezone`, `station_name` |
| GET | `/audio/{filename}` | Serve FLAC clip from `data/detections/` |
| GET | `/spectrogram/{filename}` | Serve mel-spectrogram PNG (LRU-cached, slate-900 background) |
| GET | `/stream/detections` | SSE stream — pushes new detections as `detection` events |
| GET | `/healthz` | `{"status": "ok"}` health check |

Period values accepted by analytics endpoints: `today`, `7d`, `30d`, `90d`, `all` (and `custom` with `date_from`/`date_to`).

## Database schema

```
detections
    id                  INTEGER  PK
    timestamp           TIMESTAMPTZ
    species             TEXT     (primary model IOC common name)
    bto_name            TEXT     (BTO British name; NULL if unmapped)
    confidence          FLOAT    (primary model confidence score)
    clip_path           TEXT
    model               TEXT     ("birdnet" | "perch")
    primary_confidence  FLOAT    (raw primary score; NULL when CV not run)
    cross_validated     BOOLEAN  (NULL = not applicable; True/False = CV ran)
    cv_secondary_model  TEXT
    cv_species          TEXT
    cv_bto_name         TEXT
    cv_confidence       FLOAT
    cv_agree            BOOLEAN
    flagged             BOOLEAN  (True when disagreement + on_disagree = "flag")

detection_results       (secondary candidates, FK → detections)
species_info            (seeded from species_bto_FINAL_filtered.json on first run)
    name, scientific_name, british_list_status, population_estimate,
    bto_2letter_code, bto_5letter_code, species_status, uk_bocc,
    birdfacts_url, international_english_name, group_name
```

## Optional features (disabled by default in config.toml)

- **PostgreSQL / TimescaleDB**: set `[database] type = "postgresql"`, install `psycopg2-binary`. Note: the dashboard always reads SQLite directly.
- **MQTT**: set `[mqtt] enabled = true`, requires `paho-mqtt` (already in `requirements.txt`).
- **birdmap.co.uk forwarding**: set `[birdmap] enabled = true`, requires API key.
- **Cross-validation**: set `[cross_validation] enabled = true`. Both BirdNET and Perch must be installed. See notes above.
- **Perch v2 model**: set `[inference] model = "perch"`. Requires:
  1. `pip install 'perch-hoplite[tf]'` (~2 GB TF install)
  2. Kaggle API token at `~/.config/kaggle/kaggle.json` — model (~400 MB) downloads on first run and is cached in `~/.cache/kagglehub/`
  3. Perch uses 5-second windows; the rolling audio buffer resizes automatically
  4. BOU filter works via scientific-name matching (eBird codes → BTO names via `species_bto_FINAL_filtered.json`); BirdNET label locale is irrelevant for Perch
